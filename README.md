# 聚点

面向广州、佛山公共交通会合场景的微信小程序。它根据成员提交的模糊出发点、通勤上限与会合策略，给出更合适的“地铁站 + 商圈”碰面建议。

## 当前开发阶段

第一期已用原生微信小程序和本地演示数据实现核心流程：

- 发起人设置人数、推荐策略与最远通勤上限；
- 通过邀请文案或微信分享邀请参与者；
- 参与者直接点按广佛示意地图或站点列表，提交自己的模糊出发区域；
- 未填齐时实时显示“暂定推荐 · 还有 X 人未填写”；
- 按智能平衡、总通勤、最远成员、少换乘、餐饮优先切换推荐；
- 发起人确认地点，生成导航入口提示与分享卡片；
- 确认后的会合保存在当前设备的本机历史中。

## 本地预览

1. 用微信开发者工具导入本仓库根目录。
2. 当前 `project.config.json` 使用 `touristappid`，可先以游客 AppID 预览；接入真实能力前替换为自己的小程序 AppID。
3. 在首页依次体验“发起一场聚会 → 生成邀请链接 → 我来填写出发点 → 点地图或展开地图精细选择 → 提交我的出发点 → 发起人确认当前地点”。
4. 在仓库根目录运行 `npm test`，可验证本地推荐、位置提交、历史记录、页面注册和视图文案。

## 当前接入边界

地图选点已经可以在小程序内完成“站点附近”的交互选择，但地图底图和路线耗时目前使用本地演示数据。以下能力已保留适配边界，取得配置后再接入真实服务：

- 微信一键登录与用户身份；
- 百度地图（默认）/ 高德地图的地理编码、路线规划和导航；
- CloudBase 或业务后端的场次链接、多人实时同步与历史云端存储；
- 餐厅 POI、介绍与商业化权益；
- 支付与会员能力。
